# 📚 Книжный клуб с ИИ-консультантом

Telegram-бот для организации книжного клуба с искусственным интеллектом, который помогает подбирать книги, генерирует вопросы для обсуждения и создает персональные рекомендации.

## 🌟 Основные функции

### Для участников (бесплатный уровень)
- 📝 **Регистрация в клубе**: Сбор имени, любимых жанров, целей чтения
- 📋 **Анкета для подбора книг**: ИИ предлагает 3-5 вариантов на основе ответов
- 🗳️ **Организация встреч**: Голосование за даты, напоминания, ссылки на встречи
- ❓ **Генератор вопросов**: Уникальные вопросы для обсуждения от ИИ
- 🔗 **Интеграция с сервисами**: Партнерские ссылки на книжные магазины
- 📖 **Личный читательский дневник**: Сохранение мыслей о прочитанном
- 🎯 **Рекомендации от ИИ**: Персональные подборки на основе предпочтений

### Для монетизации (платная подписка)
- 💎 **Персональная подборка**: Ежемесячные презентации книг с объяснениями
- 📊 **Расширенный анализ**: PDF-досье на книги с ИИ-анализом
- 👥 **Закрытое комьюнити**: Доступ к эксклюзивному чату и AMA-сессиям
- 🎫 **Эксклюзивные события**: Онлайн-встречи и мастер-классы
- ⚡ **Ранний доступ**: Первоочередное голосование и скидки
- 🎧 **Аудио-конспекты**: 10-минутные аудио-дайджесты книг

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения
Скопируйте файл `.env.example` в `.env` и заполните его:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
DATABASE_URL=sqlite:///bookclub.db
```

### 3. Получение токенов

#### Telegram Bot Token:
1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

#### OpenAI API Key:
1. Зарегистрируйтесь на [OpenAI](https://platform.openai.com/)
2. Перейдите в API Keys
3. Создайте новый ключ и скопируйте его

### 4. Запуск бота
```bash
python bot.py
```

## 🛠️ Технический стек

- **Python 3.8+** - основной язык программирования
- **python-telegram-bot** - библиотека для работы с Telegram API
- **OpenAI API** - генерация рекомендаций и вопросов
- **SQLite** - база данных для хранения информации
- **APScheduler** - планировщик автоматических уведомлений

## 📊 База данных

Бот использует SQLite с следующими таблицами:
- `users` - информация об участниках
- `books` - каталог книг
- `votes` - голосования за книги
- `meetings` - информация о встречах
- `discussion_questions` - вопросы для обсуждения
- `reading_diaries` - читательские дневники

## 🔧 Настройка администратора

В файле `admin_panel.py` укажите ID администраторов:

## 🐛 Устранение неполадок

### Бот не запускается:
1. Проверьте токен в `.env`
2. Убедитесь, что все зависимости установлены
3. Проверьте версию Python (требуется 3.8+)

### ИИ не отвечает:
1. Проверьте OpenAI API ключ
2. Убедитесь, что на счете есть средства
3. Проверьте интернет-соединение

### База данных не создается:
1. Проверьте права доступа к папке
2. Убедитесь, что установлен sqlite3
